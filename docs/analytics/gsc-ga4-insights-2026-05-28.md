```
[Pain Point/Benefit] + [Action] + [Destination] + [Year]

예시:
- "Cheapest Way to Send Money to India from Korea 2026"
- "7 Ways to Save Money on Remittance Fees"
- "E9 Visa Korea: Complete Salary Guide 2026"
```

**저CTR 제목 패턴 (피해야 함)**:
```
[Generic Action] + [Technical Term] + [Country]

피해야 할 예시:
- "Real-Time Remittance Guide Vietnam 2026" (CTR 0%)
- "Send Money to Philippines Guide" (CTR 0%)
```
