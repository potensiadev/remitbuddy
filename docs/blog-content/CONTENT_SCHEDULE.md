## Content Creation Guidelines

### ⚠️ CRITICAL: Language Rules
- **ALL blog content MUST be written in English ONLY**
- **NO Korean text allowed** in any part of the content (title, body, FAQ, tables, etc.)
- Korean keywords are for SEO research only - never include them in the actual content
- Target audience: Non-native English speakers (use simple, clear English)
- Exception: Only the CONTENT_SCHEDULE.md file itself can contain Korean for internal planning

### SEO Requirements
- Primary keyword in title, H1, first paragraph
- 1,500-2,500 words
- FAQ section with 5-8 questions
- Internal links to related content
- Meta title under 60 characters
- Meta description 150-160 characters
