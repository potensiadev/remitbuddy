## 3. 핵심 인사이트

### 3.1 베트남 (KRW-VND) - 최우선 타겟
- **이벤트 수 1위**: 28건 (전체의 약 22%)
- **고액 송금 (1M-3M)** 수요 집중
- **액션**: 베트남 송금 관련 콘텐츠 강화 필요
  - 베트남 실시간 송금 가이드 (발행 완료)
  - 베트남 명절(Tết) 송금 가이드 계획

### 3.2 네팔 (KRW-NPR) - 2위 타겟
- **이벤트 수 2위**: 16건
- **특징**: 고액 송금 (1M-3M) 수요 높음
- **액션**: 네팔 송금 가이드 발행 완료, 추가 콘텐츠 고려
  - 네팔 명절 송금 가이드
  - E9Pay 집중 소개 (이전 데이터에서 E9Pay 선호)

### 3.3 싱가포르 (KRW-SGD) - 신규 발견
- **이벤트 수**: 6건 (예상 외로 높음)
- **특징**: 고액 송금 수요
- **액션**: 싱가포르 송금 가이드 콘텐츠 검토
  - 타겟: 싱가포르 거주 한국인? 또는 싱가포르로 송금하는 외국인?

### 3.4 필리핀 (KRW-PHP) - 기존 타겟
- **이벤트 수**: 4건 (고액대)
- **특징**: GCash 가이드 발행 완료
- **액션**: 저액대(0-100k, 100k-500k) 데이터도 확인 필요

### 3.5 신규 시장 발견
- **우즈베키스탄 (UZS)**: 3건 - 중앙아시아 외국인 근로자
- **방글라데시 (BDT)**: 3건 - 남아시아 외국인 근로자
- **중국 (CNY)**: 4건 - 중국 유학생/근로자
- **액션**: 수요 모니터링 후 콘텐츠 계획

### 3.6 디바이스별 행동 차이
- **데스크톱**: 이벤트 수 높음 (심층 비교)
- **모바일**: 사용자 수는 많지만 이벤트 수 적음 (빠른 확인)
- **액션**: 모바일 UX 최적화, 빠른 비교 기능 강조

## 8. 데이터 정확도 개선 (2026-05-10 추가)

### 문제점
- 베트남(VND)이 default 국가로 설정되어 있어 데이터 왜곡 가능성
- 사용자가 실제로 베트남 송금을 원하는지, 그냥 default로 클릭한 건지 구분 불가

### 해결책: 코드 수정 완료

**추가된 이벤트 파라미터:**

| 파라미터 | 설명 | 값 예시 |
|---------|------|--------|
| `is_default_country` | 사용자가 국가를 변경했는지 여부 | `true` (default 그대로) / `false` (직접 선택) |
| `browser_language` | 브라우저 언어 설정 | `vi`, `en`, `ko`, `ne` 등 |

### GA4 맞춤 측정기준 등록 필요

```
관리 > 데이터 표시 > 맞춤 정의 > 맞춤 측정기준 만들기
```

| 측정기준 이름 | 범위 | 이벤트 파라미터 |
|--------------|------|----------------|
| Is Default Country | 이벤트 | `is_default_country` |
| Browser Language | 이벤트 | `browser_language` |

### 분석 방법

**1. 베트남 실제 수요 확인:**
```
필터: corridor = KRW-VND AND is_default_country = false
→ 실제로 베트남을 선택한 유저만 필터링
```

**2. Default 사용 비율 확인:**
```
측정기준: is_default_country
측정항목: 이벤트 수
→ true vs false 비율 확인
```

**3. 언어별 국가 선택 패턴:**
```
측정기준: browser_language, corridor
측정항목: 이벤트 수
→ vi(베트남어) 사용자가 VND 선택하면 실제 베트남 유저 가능성 높음
```

### 예상 분석 결과

| Corridor | is_default_country | 이벤트 수 | 해석 |
|----------|-------------------|----------|------|
| KRW-VND | true | 15 | Default 그대로 (신뢰도 낮음) |
| KRW-VND | false | 13 | 직접 선택 (신뢰도 높음) |
| KRW-PHP | false | 10 | 직접 선택 (신뢰도 높음) |
| KRW-NPR | false | 8 | 직접 선택 (신뢰도 높음) |

**결론:** `is_default_country = false`인 데이터만 보면 정확한 국가별 수요 파악 가능
